API 規格說明

📥 輸入 (Input)

主辦方將透過 HTTP POST 傳送 JSON 格式的「學習需求」：

{
  "request_id": "uuid-string",
  "topic": "Transformer 架構中的 Self-Attention 機制",
  "student_persona": "我是高中一年級學生，沒學過微積分，但懂基礎矩陣運算",
  "category": "cs",
  "preferred_duration": "5-10min",  // optional
  "language": "zh-TW"
}

📤 輸出 (Output)

您的 API 應回傳以下 JSON 格式：

{
  "request_id": "uuid-string",
  "status": "success",
  "video": {
    "url": "https://your-cdn.com/video.mp4",
    "duration_seconds": 342,
    "format": "mp4",
    "resolution": "1080p"
  },
  "supplementary_materials": [  // Optional
    {
      "type": "slides",
      "url": "https://your-cdn.com/slides.pdf",
      "title": "教學投影片"
    },
    {
      "type": "code",
      "url": "https://your-cdn.com/example.py",
      "title": "範例程式碼"
    }
  ],
  "metadata": {
    "style": "slides_voiceover",  // slides_voiceover | avatar | animation
    "ai_model": "your-model-name",
    "generation_time_seconds": 120
  }
}

關於教學怪物

                    
打造 AI 教學影片的公開競技場

                


                

                    

                        
🎯 我們的使命

                        

                            教學怪物是一個開放的 AI 教學影片評測平台，靈感來自 Chatbot Arena 的成功模式。
                            我們相信，透過公開、公平的競爭，可以推動 AI 教學技術的快速進步，
                            最終讓每個人都能享受到最優質的 AI 個人化教學體驗。
                        

                    


                    

                        
⚙️ 評分機制

                        

                            

                                
ELO 評分系統

                                
採用類似西洋棋的 ELO 評分系統，每場對決後根據勝負與雙方實力差距動態調整分數

                            

                            

                                
盲測機制

                                
評審時隱藏 AI 模型身份，確保評分完全基於教學品質而非品牌偏見

                            

                            

                                
多維度評估

                                
結合人工投票與 AI 助教評分，從準確性、清晰度、視覺呈現、適合程度等多角度評估
